# NightWalk sleep funnel

Interactive quiz, 12-week evening walking plan, and paywall demo for team review.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## What's inside

- Sleep-first funnel based on the WalkMore flow
- Sleep and weight education backed by research
- 12-week walking plan outline
- Demo checkout (no real payments)

## Brand

**NightWalk.** Walk by day. Sleep by night.
